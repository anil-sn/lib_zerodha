# Kite Connect API Complete Reference\n\nThis document provides a comprehensive overview of all Kite Connect APIs implemented in lib_zerodha.\n\n## Authentication APIs\n\n### Login Flow\n```\n1. User visits: https://kite.trade/connect/login?api_key=YOUR_API_KEY\n2. After login, Kite redirects to: YOUR_REDIRECT_URL?request_token=REQUEST_TOKEN&action=login&status=success\n3. Use request_token to generate access_token\n```\n\n### Session Management\n| Method | Endpoint | Description |\n|--------|----------|-------------|\n| `generate_session()` | POST /session/token | Generate access token from request token |\n| `invalidate_session()` | DELETE /session/token | Logout and invalidate access token |\n| `profile()` | GET /user/profile | Get user profile and broker details |\n| `margins()` | GET /user/margins | Get account margins for equity/commodity |\n\n## Market Data APIs\n\n### Instrument Master\n| Method | Endpoint | Description |\n|--------|----------|-------------|\n| `instruments()` | GET /instruments | Complete instruments list (CSV format) |\n| `instruments(exchange)` | GET /instruments/{exchange} | Exchange-specific instruments |\n\n**Supported Exchanges**: NSE, BSE, NFO, CDS, BFO, MCX\n\n### Real-Time Market Data\n| Method | Endpoint | Description |\n|--------|----------|-------------|\n| `quote()` | GET /quote | Real-time quotes with OHLC and depth |\n| `ohlc()` | GET /quote/ohlc | OHLC data only |\n| `ltp()` | GET /quote/ltp | Last traded prices only |\n\n**Quote Response Structure**:\n```json\n{\n  \"NSE:RELIANCE\": {\n    \"instrument_token\": 738561,\n    \"timestamp\": \"2026-01-07T15:30:00+0530\",\n    \"last_price\": 2650.75,\n    \"ohlc\": {\n      \"open\": 2640.00,\n      \"high\": 2655.00,\n      \"low\": 2635.00,\n      \"close\": 2645.50\n    },\n    \"volume\": 1234567,\n    \"average_price\": 2647.25,\n    \"oi\": 0,\n    \"depth\": {\n      \"buy\": [\n        {\"price\": 2650.50, \"quantity\": 100, \"orders\": 5}\n      ],\n      \"sell\": [\n        {\"price\": 2651.00, \"quantity\": 200, \"orders\": 3}\n      ]\n    }\n  }\n}\n```\n\n### Historical Data\n| Method | Endpoint | Description |\n|--------|----------|-------------|\n| `historical_data()` | GET /instruments/historical/{token}/{interval} | Historical OHLCV data |\n\n**Supported Intervals**: minute, 2minute, 3minute, 5minute, 10minute, 15minute, 30minute, 60minute, day\n\n**Parameters**:\n- `from` (date): From date (YYYY-MM-DD)\n- `to` (date): To date (YYYY-MM-DD)\n- `continuous` (bool): Continuous contract for futures\n- `oi` (bool): Include Open Interest data\n\n## Portfolio APIs\n\n### Positions & Holdings\n| Method | Endpoint | Description |\n|--------|----------|-------------|\n| `positions()` | GET /portfolio/positions | Day and net positions |\n| `holdings()` | GET /portfolio/holdings | Long-term holdings |\n\n**Position Types**:\n- **Day**: Intraday positions (will be auto-squared off)\n- **Net**: Overnight positions (carried forward)\n\n### Portfolio Analysis\n```python\n# Get complete portfolio\nportfolio = kite.get_portfolio()\n\n# Convert to pandas for analysis\npositions_df = portfolio.to_dataframe(\"positions\")\nholdings_df = portfolio.to_dataframe(\"holdings\")\n\n# Portfolio metrics\ntotal_pnl = portfolio.total_pnl\ntotal_value = portfolio.total_value\nmargin_available = portfolio.margin.total_available\n```\n\n## Order Management APIs\n\n### Order Placement\n| Method | Endpoint | Description |\n|--------|----------|-------------|\n| `place_order()` | POST /orders/{variety} | Place a new order |\n| `modify_order()` | PUT /orders/{variety}/{order_id} | Modify pending order |\n| `cancel_order()` | DELETE /orders/{variety}/{order_id} | Cancel pending order |\n\n**Order Varieties**: regular, bo (bracket), co (cover), amo (after market)\n\n**Order Parameters**:\n```python\norder_id = kite.place_order(\n    exchange=\"NSE\",           # NSE, BSE, NFO, etc.\n    tradingsymbol=\"RELIANCE\", # Trading symbol\n    transaction_type=\"BUY\",   # BUY or SELL\n    quantity=1,               # Number of shares/lots\n    product=\"CNC\",            # CNC, MIS, NRML\n    order_type=\"LIMIT\",       # MARKET, LIMIT, SL, SL-M\n    price=2650.00,           # Limit price (for LIMIT orders)\n    trigger_price=2640.00,   # Trigger price (for SL orders)\n    disclosed_quantity=0,     # Iceberg quantity\n    validity=\"DAY\",          # DAY or IOC\n    tag=\"my_strategy\"        # Custom tag\n)\n```\n\n**Product Types**:\n- **CNC**: Cash and Carry (delivery)\n- **MIS**: Margin Intraday Square-off\n- **NRML**: Normal (for F&O)\n\n**Order Types**:\n- **MARKET**: Market order (immediate execution)\n- **LIMIT**: Limit order (at specified price or better)\n- **SL**: Stop Loss (triggers market order)\n- **SL-M**: Stop Loss Market (triggers limit order)\n\n### Order Tracking\n| Method | Endpoint | Description |\n|--------|----------|-------------|\n| `orders()` | GET /orders | All orders for the day |\n| `order_history()` | GET /orders/{order_id} | Order modification history |\n| `trades()` | GET /trades | All executed trades |\n| `order_trades()` | GET /orders/{order_id}/trades | Trades for specific order |\n\n## WebSocket APIs\n\n### Real-Time Data Streaming\n\n**Connection URL**: `wss://ws.kite.trade/?api_key={api_key}&access_token={access_token}`\n\n### Subscription Modes\n| Mode | Description | Data Included |\n|------|-------------|---------------|\n| `ltp` | Last Traded Price | instrument_token, last_price |\n| `quote` | Quote Data | LTP + OHLC + volume + average_price |\n| `full` | Full Market Data | Quote + market depth + OI |\n\n### WebSocket Commands\n```python\n# Subscribe to instruments\nws.subscribe([738561, 408065], mode=\"quote\")\n\n# Change subscription mode\nws.set_mode([738561], \"full\")\n\n# Unsubscribe\nws.unsubscribe([738561])\n```\n\n### Tick Data Structure\n```python\n{\n    \"instrument_token\": 738561,\n    \"timestamp\": datetime(2026, 1, 7, 15, 30, 0),\n    \"last_price\": 2650.75,\n    \"ohlc\": {\n        \"open\": 2640.00,\n        \"high\": 2655.00, \n        \"low\": 2635.00,\n        \"close\": 2645.50\n    },\n    \"volume\": 1234567,\n Best Practices\n\n### API Rate Limits\n- **REST API**: 10 requests/second\n- **WebSocket**: 1000 instruments per connection\n- **Historical Data**: 60 requests/minute\n\n### Connection
